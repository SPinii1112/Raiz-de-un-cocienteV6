# Clase de Matemática: Propiedad de la Raíz de un Cociente (7° Grado)

Aplicación interactiva diseñada para la enseñanza de la propiedad **Raíz de un Cociente** en 7° grado de educación secundaria.

## 🚀 ¿Cómo publicar esto en la web con GitHub Pages?

1. Crea un repositorio nuevo en [GitHub](https://github.com/new):
   - Dale un nombre (por ejemplo: `raiz-de-un-cociente`).
   - Déjalo en modo **Public** (Público).
   - No marques "Add a README file" (ya lo tenemos listo).
2. Sube estos archivos al repositorio.
3. Activa **GitHub Pages**:
   - En tu repositorio de GitHub, ve a **Settings** (Configuración) > pestaña **Pages** (en el menú lateral izquierdo).
   - En **Branch**, selecciona `main` y la carpeta `/(root)`.
   - Haz clic en **Save**.
4. ¡Listo! En 1 minuto GitHub te dará un enlace público como:
   `https://tu-usuario.github.io/raiz-de-un-cociente/`
   Ese es el enlace que puedes compartirle a tus alumnos o proyectar como código QR en la pizarra.

## 📱 Contenido
- **1. Explicación Teórica:** Breve, intuitiva y adaptada a 7° grado.
- **2. Ejemplos Resueltos:** 3 ejemplos con números pertenecientes a $\mathbb{Q}$ y raíces exactas.
- **3. Práctica Interactiva (20 ejercicios):** Validación instantánea que indica si la respuesta es correcta o si deben reintentar, sin revelar la solución.
